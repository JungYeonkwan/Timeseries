# Prophet으로 소비 지출 데이터 예측
## 시간 변수만 사용 했을 경우
<img width="1200" height="600" alt="Forecasting" src="https://github.com/user-attachments/assets/7c68e9c5-2e06-409a-91f6-5af7ba3b842a" />
시간 정보만 사용하기 때문에, R²가 매우 작게(R² ≈ 0.037) 나오는 걸 볼 수 있고, 이는 “시간만으로는 Consumption 변동을 거의 설명하지 못한다”는 의미를 가진다.<br><br>

## 다양한 경제 변수(소득, 생산, 저축, 실업률)를 사용했을 경우
<img width="1200" height="500" alt="Forecasting_TSLM" src="https://github.com/user-attachments/assets/121587be-5b67-4af0-9350-3d65955ee42c" />
다양한 경제 변수(소득, 생산, 저축, 실업률)들을 회귀자로 넣었기 때문에,
단변량 Prophet보다 훨씬 큰 R² 값(R² ≈ 0.77)이 나오는 걸 기대할 수 있다.<br>
→ “추가 변수들이 소비 변동을 설명하는 데 큰 역할을 한다”는 걸 수치와 그림으로 확인하는 셈이다.<br><br>

### R²는 0 ~ 1 사이의 값을 가지며, 보통 이렇게 해석한다.
- 1에 가까울수록 → 모델이 데이터의 변동을 잘 설명
- 0에 가까울수록 → 모델이 평균 수준 이상으로 데이터를 설명하지 못함
- 예: R² = 0.76 → 전체 변동의 약 76%를 모델이 설명하고 있다

### 단변량 Prophet 코드에서의 R²<br>
→ 시간 정보만으로 Consumption 변동을 어느 정도 설명하는지 보여줌<br>
→ 값이 매우 작다면, “시간만으로는 거의 설명하지 못한다”는 신호<br>

### Prophet + 회귀자 코드에서의 R²<br>
→ 시간 + 경제 변수들을 모두 사용했을 때, Consumption 변동을 얼마나 설명하는지 보여줌<br>
→ 단변량 대비 R²이 크게 올라가면<br>
“Income, Production, Unemployment, Savings가 소비 변동을 설명하는 핵심 요인”이라는 해석 가능

### 왜 R²가 중요한 지수인가?
#### 1. 설명력(적합도)을 직관적으로 보여줌
- “현재 모델이 타깃 변수의 변동성 중 얼마나 많은 부분을 설명하고 있는가?”를
  하나의 숫자로 요약해 주는 지표.

#### 2. 모델/구조 비교에 유용
- 단변량 Prophet vs Prophet + regressors
- 선형회귀 vs 다른 시계열 모델<br>
이런 식으로 서로 다른 모델을 같은 데이터 위에서 비교할 때,<br>
R²을 지표로 사용하면 “어떤 모델 구조가 더 데이터를 잘 설명하는지”를 쉽게 비교 가능.

#### 3. 변수 선택의 효과를 확인 가능
- 설명 변수를 추가했을 때 R²가 크게 증가한다면,<br>
그 변수들이 실제로 타깃을 설명하는 데 중요한 역할을 한다는 근거가 될 수 있다.

#### 4. 시각화와 함께 사용할 때 이해도 상승
- 시계열 그래프에서 실제 vs 예측이 잘 맞고,
- 산점도에서 점들이 y=x 대각선 주변에 잘 모여 있을수록,<br>
R² 값이 높게 나오는 경향이 있다.<br>
→ 숫자(R²)와 그림(플롯)을 함께 보면 모델 적합도를 정성+정량 두 관점에서 동시에 이해할 수 있다.
