1. 개요

XOR 문제에서 은닉층(hidden layer)이 어떤 역할을 하는지를
좌표 공간의 변화를 통해 직관적으로 이해하기 위해 작성되었다.

XOR 문제는 입력 공간 (x1, x2)에서는 선형 분리가 불가능하지만,
은닉층의 비선형 변환을 거치면 선형 분리가 가능한 공간으로 맵핑된다.

본 코드는

입력 공간에서의 XOR 데이터 분포

은닉층(Sigmoid 출력 공간)에서의 데이터 재배치
를 시각적으로 비교하는 것을 목표로 한다.

2. XOR 문제 설명

XOR의 출력은 다음과 같이 정의된다.

이때 입력 공간 (x1, x2)에서는
XOR = 0 과 XOR = 1 을 하나의 직선으로 분리할 수 없다.

3. 데이터 생성 방식

입력 데이터는 (0,0), (0,1), (1,0), (1,1) 네 개의 기준점 주변에서 생성된다.

각 기준점 주변에 정규분포 노이즈를 추가하여 데이터를 만든다.

입력은 [0,1] 범위로 제한된다.

XOR 라벨은 다음 방식으로 계산된다.

x_i > 0.5  ->  1
x_i <= 0.5 ->  0

y = x1 XOR x2

4. 은닉층 구조

본 시각화에서는 은닉층에 두 개의 뉴런을 사용한다.

은닉층의 선형결합은 다음과 같다.

z1 =  3 - 2*x1 - 2*x2
z2 = -1 + 2*x1 + 2*x2


각 선형결합 결과는 Sigmoid 함수를 통해 변환된다.

n = 1 / (1 + exp(-z))


이 과정을 통해 입력 공간의 점들은
은닉층 출력 공간 (n1, n2)로 맵핑된다.

5. 시각화 구성

시각화는 두 개의 패널로 구성된다.

(1) 입력 공간 (Input Layer)

좌표: (x1, x2)

색상:

파란색: XOR = 0

빨간색: XOR = 1

XOR 데이터가 비선형적으로 섞여 있음을 확인할 수 있다.

(2) 은닉층 출력 공간 (Hidden Layer)

좌표: (n1, n2)

Sigmoid 출력이므로 값의 범위는 [0,1]

입력 공간에서는 섞여 있던 XOR 데이터가
공간적으로 분리된 형태로 재배치됨을 확인할 수 있다.

이 결과는 은닉층의 비선형 변환이
XOR 문제를 선형 분리 가능하게 만드는 핵심 역할을 한다는 것을 보여준다.

6. 실행 방법
python main.py


또는 코드 파일에서 아래 함수를 직접 실행한다.

plot_xor_and_hidden(n=20, noise=0.06, seed=3)


n : 데이터 개수 (15~25 권장)

noise : 데이터 분산 정도

seed : 난수 고정용

7. 핵심 요약

XOR 문제는 입력 공간에서는 선형 분리가 불가능하다.

은닉층의 선형결합과 Sigmoid 변환은 입력 공간을 비선형적으로 변형한다.

그 결과 XOR 데이터는 은닉층 공간에서 분리 가능한 형태로 재배치된다.

본 시각화는 은닉층이 왜 필요한지를 직관적으로 보여준다.
